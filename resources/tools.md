# RAG Tools and Technology Directory

Check official documentation for current APIs, installation steps, pricing, licences and free-tier limits. Open source does not mean zero operating cost.

## Languages
- Python: strong AI/ML ecosystem; common for ingestion and experiments.
- TypeScript: useful for web applications and Node.js backends.

## Models and embeddings
- OpenAI API: hosted models; API usage may be paid.
- Sentence Transformers: open-source embedding models that can run locally.
- Hugging Face: model discovery and tooling.
- Ollama: local model runtime; hardware requirements vary.

## Frameworks
- LangChain: integrations and orchestration.
- LlamaIndex: data ingestion, indexing and retrieval workflows.
- Haystack: search and RAG pipelines.
- Plain Python or TypeScript: excellent for learning fundamentals before adopting a framework.

## Vector and search stores
FAISS, Chroma, Qdrant, PostgreSQL + pgvector, Pinecone, Weaviate, Elasticsearch and OpenSearch.

## Document processing
- PyMuPDF and pypdf: PDF extraction.
- python-docx: DOCX processing.
- Beautiful Soup: HTML parsing.
- Tesseract OCR: optical character recognition; quality depends on scan and language.

## Backend and testing
FastAPI, Node.js, Express, Fastify, pytest, Vitest, Jest, Postman, Bruno and curl.

## Developer tools
Git, GitHub, VS Code, Docker, Jupyter and SQLite.

## Choosing a stack
For local learning, consider Python + Sentence Transformers + Chroma or FAISS. For an app already using relational data, PostgreSQL + pgvector may be convenient. Compare managed services against the cost and responsibility of self-hosting.
